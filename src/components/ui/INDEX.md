# src/components/ui

## Purpose

Small reusable UI primitives used across BentoLife.

## Start Here

- `button.tsx`, `badge.tsx`, `input.tsx`, `label.tsx` - core form/action primitives.
- `dialog.tsx`, `drawer.tsx`, `dropdown-menu.tsx`, `tooltip.tsx`, `toast.tsx`, `tabs.tsx` - composed interaction primitives.
- `card.tsx`, `empty.tsx`, `skeleton.tsx`, `separator.tsx` - layout/status primitives.

## Do Not Put Here

- Product-specific module behavior.
- One-off components that are not reused.
