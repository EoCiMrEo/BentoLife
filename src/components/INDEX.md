# src/components

## Purpose

React UI surfaces and reusable components for the BentoLife renderer.

## Start Here

- `modules/` - daily module surfaces and shared generated module UI.
- `architect/` - advanced diagnostics and configuration center.
- `dashboard/` - Dashboard hub and widget composition.
- `settings/` - Vault and data settings.
- `widgets/` - Dashboard widget canvas, cards, settings dialog, and renderer primitives.
- `vault/` - vault status/onboarding surface.
- `ui/` - small reusable UI primitives.

## Tests

Component tests live in `src/test/components/`.

## Do Not Put Here

- Service adapters or persistent storage logic.
