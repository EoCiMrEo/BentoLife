# BentoLife Diagrams

Mermaid diagrams in this folder are diffable source docs. They explain behavior and ownership without becoming generated images.

## Start Here

- `app-behavior-diagram.md` - app-wide navigation and ownership.
- `module-behavior-diagrams.md` - Notes, Todos, Contacts, and Habits behavior.
- `system-surface-diagrams.md` - Architect, Settings, Import Review, Recovery, Trash/Archive, Widgets, and Theme surfaces.

## Do Not Put Here

- Screenshots or exported PNGs.
- New product requirements without a matching task or contract update.
