# Getting Started

BentoLife is a local Markdown desktop workspace.

## Vault

Create or choose a BentoLife vault folder. The app stores readable Markdown content in the vault and app state in the vault metadata folder.

## Main Areas

- Dashboard
- Notes
- Todos
- Contacts
- Habits
- Settings
- Architect
- Trash
- Archive

## Language

The app UI can switch between English and Vietnamese. User Markdown is not translated or rewritten.
