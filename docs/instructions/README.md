# BentoLife User Instructions

Use these guides when setting up or customizing BentoLife.

- [Getting Started](getting-started.md)
- [Content Guide](content-guide.md)
- [Theme and Settings Guide](themes-and-settings.md)
- [Import and Transfer Guide](import-transfer.md)

BentoLife is local-first. Your content lives in a Markdown vault, while app-owned state such as dashboard layout, registry state, themes, search indexes, trash, archive, and import staging lives under `.bentolifelayout/` inside that vault.
