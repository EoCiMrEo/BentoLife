# src/components/widgets

## Purpose

Dashboard widget shell, canvas, settings, and shared widget primitives.

## Start Here

- `WidgetCanvas.tsx` - Dashboard widget grid, picker, responsive columns, and custom mode.
- `WidgetCard.tsx` - Widget frame, chrome, settings dialog entry, and renderer host.
- `WidgetManager.tsx` - Architect Dashboard widget management surface.
- `WidgetPrimitives.tsx` - Shared visual primitives that are actively used by widget renderers.
