# BentoLife

BentoLife is a local-first desktop life dashboard built around a Markdown vault.

## What it does

- Organize notes, todos, contacts, and habits in a local workspace.
- Add widgets to a calm personal dashboard.
- Keep user content readable as Markdown.
- Support English and Vietnamese app UI without rewriting user Markdown.

## Getting started

Download the latest Windows installer from the Releases page.

After installing, create or choose a BentoLife vault. Your content stays in the vault as Markdown, while BentoLife stores app state inside the vault metadata folder.

## Public release boundary

This repository is for public releases. Development logs, task trackers, private planning docs, editor folders, test output, and CI-only files are not part of this public release repository.

The release exporter preserves this root README and the root license files, so public-facing repository information can be reviewed separately from the development README.
