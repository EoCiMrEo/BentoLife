## Translation Notes

- Translate app UI and system text only. Do not translate or rewrite user-authored Markdown titles, body text, tags, checklist items, or raw Markdown previews.
- Keep internal IDs, paths, schema keys, and technical file names unchanged unless they are being shown as friendly labels.
- Prefer calm, natural product wording over formal enterprise wording.
- Use `Tiện ích` for user-facing Widget text. Avoid mixed labels such as `Widget Tiện ích`.
- Use `Danh bạ` for the Contacts module as a product area. Use `liên hệ` for an individual contact record when the sentence is about one person.
- Keep `Markdown`, `schema`, `snapshot`, and `backlinks` as technical terms unless a user-facing sentence needs a short explanation.
- Capitalize product areas consistently when they name a BentoLife screen, for example `Bảng điều khiển`, `Cài đặt`, `Kiến trúc`, `Thùng rác`, and `Lưu trữ`.
